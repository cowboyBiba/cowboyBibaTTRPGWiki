Вы решили создать своего приключенца. Ниже приведён пошаговый гайд по созданию персонажа. В конце этой страницы также представлены несколько вариантов листов персонажа, на русском и английском.

Для начала нужно определить характеристики вашего героя. 

**Характеристики**:
- Сила - отвечает за удары тяжёлым оружием, выбивание дверей, важно для **Воинов**.
- Ловкость - отвечает за стрельбу из лука и бой легким/фехтовальным оружием, акробатику и скрытность. Важно для **Воров**.
- Телосложение - отвечает за крепкость вашего персонажа, задержку дыхания, сопротивление ядов. Важно для всех.
- Интеллект - отвечает за использование заклинаний Волшебников, анализ, расследование, изучение, расшифровку рун. Важно для **Волшебников** и **Рейнджеров**.
- Мудрость - отвечает за использование заклинаний Жрецов, внимательность и интуицию. Важно для **Жрецов**.
- Харизма - отвечает за убеждение, обман и сопротивление ментальному контролю. Важно для **Бардов** и **Ведьм**.

Для каждой из 6 характеристик бросьте 3к6. Сумма кубиков присваивается характеристике.

Если у вас нет ни одной характеристики выше 12, вы можете перебросить все характеристики.

Получившимся значениям характеристик назначаются модификаторы, которые прибавляются к проверкам:

| Значение | Модификатор |
| -------- | ----------- |
| 1        | -5          |
| 2-3      | -4          |
| 4-5      | -3          |
| 6-7      | -2          |
| 8-9      | -1          |
| 10-11    | 0           |
| 12-13    | +1          |
| 14-15    | +2          |
| 16-17    | +3          |
| 18-19    | +4          |
| 20+      | +5          |

На основе выпавших значений нужно выбрать [[Расы|расу]] и [[Классы|класс]] вашего персонажа.

Определитесь с уровнем персонажа. Обычно персонажи начинают своё приключение с 3 уровня. Об альтернативных стартах, получении опыта и прокачке можно прочитать [[Уровень, опыт и прокачка|здесь]].

Теперь нужно вычислить Очки Здоровья (ОЗ). Количество здоровья за уровень указано в вашем классе.

Также совершите броски таланта по таблице вашего класса. За каждый нечётный уровень вы получаете 1 бросок таланта.

Выберите [[Предыстории|предысторию]] персонажа.

Выберите мировоззрение своего персонажа:
- Хаотичный - разрушение, амбиции или зло. Придерживаются принципа "выживает сильнейший".
- Нейтральный - баланс между порядком и хаосом. Часто принимается друидами, монахами или международными торговыми конгломератами.
- Законопослушный - порядок, справедливость, добродетель. Часто руководствуются законами и "высшим благом".
Мировоззрение может меняться в процессе игры в зависимости от вашего поведения. Оно также влияет на работу некоторых волшебных предметов и заклинаний.

Стартовый капитал персонажей 2к6 x 5 золотых монет за уровень. Например, новый персонаж 3 уровня будет стартовать с 6к6 x 5 золотых монет.

На эту сумму вы можете закупить начальное [[Инвентарь|снаряжение]].

После закупки снаряжения определите ваш Класс Доспеха (КД). Он равен 10 + модификатор Ловкости. Ношение брони изменяет ваш КД.
КД определяет сложность броска атаки для попадания по вам.
