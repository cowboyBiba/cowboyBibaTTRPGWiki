Вы решили создать своего приключенца. Для начала нужно определить характеристики вашего героя. 

**Характеристики**:
- Сила - отвечает за удары тяжёлым оружием, выбивание дверей, важно для **Воинов**.
- Ловкость - отвечает за стрельбу из лука и бой легким/фехтовальным оружием, акробатику и скрытность. Важно для **Воров**.
- Телосложение - отвечает за крепкость вашего персонажа, задержку дыхания, сопротивление ядов. Важно для всех.
- Интеллект - отвечает за использование заклинаний Волшебников, анализ, расследование, изучение, расшифровку рун. Важно для **Волшебников** и **Рейнджеров**.
- Мудрость - отвечает за использование заклинаний Жрецов, внимательность и интуицию. Важно для **Жрецов**.
- Харизма - отвечает за убеждение, обман и сопротивление ментальному контролю. Важно для **Бардов**.

Для каждой из 6 характеристик бросьте 4к6, после чего отложите кубик с наименьшим результатом.  Сумма оставшихся кубиков присваивается характеристике.

Получившимся значениям характеристик назначаются модификаторы, которые прибавляются к проверкам:

| Значение | Модификатор |
| -------- | ----------- |
| 1        | -5          |
| 2-3      | -4          |
| 4-5      | -3          |
| 6-7      | -2          |
| 8-9      | -1          |
| 10-11    | 0           |
| 12-13    | +1          |
| 14-15    | +2          |
| 16-17    | +3          |
| 18-19    | +4          |
| 20+      | +5          |
На основе выпавших значений нужно выбрать [[Расы|расу]] и [[Классы|класс]] вашего персонажа.

Теперь нужно определиться с уровнем персонажа. Обычно персонажи начинают своё приключение с 3 уровня. Об альтернативных стартах, получении опыта и прокачке можно прочитать [[Уровень, опыт и прокачка|здесь]].

Теперь нужно определить Очки Здоровья (ОЗ). Количество здоровья за уровень указано в вашем классе.
