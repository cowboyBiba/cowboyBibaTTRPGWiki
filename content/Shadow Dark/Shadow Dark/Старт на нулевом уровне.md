Старт на нулевом уровне заметно сложнее, чем [[Создание персонажа|стандартное создание персонажа]], но так как **новичкам везёт**, до первого уровня вы можете пользоваться любым снаряжением без ограничений.

Определить характеристики вашего героя. 

**Характеристики**:
- Сила - отвечает за удары тяжёлым оружием, выбивание дверей, важно для **Воинов**.
- Ловкость - отвечает за стрельбу из лука и бой легким/фехтовальным оружием, акробатику и скрытность. Важно для **Воров**.
- Телосложение - отвечает за крепкость вашего персонажа, задержку дыхания, сопротивление ядов. Важно для всех.
- Интеллект - отвечает за использование заклинаний Волшебников, анализ, расследование, изучение, расшифровку рун. Важно для **Волшебников** и **Рейнджеров**.
- Мудрость - отвечает за использование заклинаний Жрецов, внимательность и интуицию. Важно для **Жрецов**.
- Харизма - отвечает за убеждение, обман и сопротивление ментальному контролю. Важно для **Бардов**.

Для каждой из 6 характеристик бросьте 3к6. Сумма кубиков присваивается характеристике.

Получившимся значениям характеристик назначаются модификаторы, которые прибавляются к проверкам:

| Значение | Модификатор |
| -------- | ----------- |
| 1        | -5          |
| 2-3      | -4          |
| 4-5      | -3          |
| 6-7      | -2          |
| 8-9      | -1          |
| 10-11    | 0           |
| 12-13    | +1          |
| 14-15    | +2          |
| 16-17    | +3          |
| 18-19    | +4          |
| 20+      | +5          |
На основе выпавших значений нужно выбрать [[Расы|расу]] и [[Предыстории|предысторию]]. До первого уровня ваш персонаж не имеет класса.

Ваши Очки Здоровья (ОЗ) равны модификатору Телосложения (минимум 1).

Также вам нужно выбрать мировозрение своего персонажа:
- Хаотичный - разрушение, амбиции или зло. Придерживаются принципа "выживает сильнейший".
- Нейтральный - баланс между порядком и хаосом. Часто принимается друидами, монахами или международными торговыми конгломератами.
- Законопослушный - порядок, справедливость, добродетель. Часто руководствуются законами и "высшим благом".
Мировозрение может меняться в процессе игры в зависимости от вашего поведения. Оно также влияет на работу некоторых волшебных предметов и заклинаний.

Персонаж 0-го уровня начинает игру с 1к4 предметов из таблицы ниже:

| 1к12 | Снаряжение             |
| ---- | ---------------------- |
| 1    | Факел                  |
| 2    | Кинжал                 |
| 3    | Шест                   |
| 4    | Короткий лук и 5 стрел |
| 5    | Верёвка 60 футов       |
| 6    | Масло, фляга           |
| 7    | Лом                    |
| 8    | Железные шипы (10)     |
| 9    | Огниво                 |
| 10   | Крюк кошка             |
| 11   | Дубинка                |
| 12   | Калтропы (мешочек)     |
Определите ваш Класс Доспеха (КД). Он равен 10 + модификатор Ловкости.
