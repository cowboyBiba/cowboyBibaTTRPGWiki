Ваш инвентарь ограничен и вы не можете носить с собой предметов больше, чем количество ваших слотов инвентаря.

Количество слотов равно вашему значению Силы.

Конверсия денег 100 медных монет (мм) = 10 серебряных монет (см) = 1 золотых монет (зм)

Ниже приведены таблицы стандартных предметов.

**Обычное снаряжение**

| Предмет            | Стоимость   | Количество вещей на 1 слот         |
| ------------------ | ----------- | ---------------------------------- |
| Стрелы (20)        | 1 зм        | 1-20                               |
| Рюкзак             | 2 зм        | 1 (первый не занимает места)       |
| Калтропы (мешочек) | 5 см        | 1                                  |
| Монеты             | Варьируется | 100 (первые 100 не занимают места) |
| Арбалетные болты   | 1 зм        | 1-20                               |
|                    |             |                                    |
